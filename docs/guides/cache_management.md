# Gerenciamento do cache

Abra **Ferramentas > RadIA > Rad IA Cache Manager** para inspecionar o cache local de respostas de IA.

O painel mostra o identificador da entrada, quantidade de caracteres, criação e último uso. O conteúdo da
resposta não é exibido, evitando exposição acidental. **Remove selected** elimina somente a entrada escolhida;
**Clear all** elimina todas. As duas operações pedem confirmação e futuras requisições recriam o necessário.

Fechar o painel ou usar **Refresh** não modifica o cache. A limpeza não altera projetos, conversas ou credenciais.
